# /load-prototype 작업 프로젝트 문맥 지정 워크플로우

1. 사용자가 명시한 프로젝트 이름을 확인합니다. (예: `MyCoolApp`)
2. 대상 폴더 `src/projects/{프로젝트이름}/`이 실제로 존재하는지 확인합니다.
3. 만약 폴더가 없다면 `/new-prototype` 으로 생성부터 해 달라고 반려합니다.
4. 폴더가 있다면, 사용자에게 "현재 작업 중인 프로젝트가 **{프로젝트이름}**(으)로 설정되었습니다. 이제 `/figma` 명령어로 이 프로젝트 하위에 화면을 추가해보세요." 라고 안내합니다.
5. AI 메모리(컨텍스트)에 명시된 프로젝트 이름을 기록해두고 이후 작업에 사용합니다.
