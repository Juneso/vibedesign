## 1. 돈으로 살 수 없는 것들 (샌델) — 척추 최상 케이스

목차가 장>절 2단이라 depth 4 가능. 메모 파일에 독자가 장 마커("1ㅣ새치기" 등)를 직접 기록 → 부착이 사실상 주어짐.
노드 제목 다수가 **목차 절 제목과 자구 일치**(줄서기의 도덕, 벌금 대 요금, 상품화 효과, 비시장 규범 밀어내기, 스카이박스화).

```
■ 돈으로 살 수 없는 것들
├─ 서론: 시장과 도덕
│   ├─ 시장의 비판단성 · p33
│   └─ (독자 생각) 시장중심주의 가치관과 공적 담론의 위기 · 무페이지
├─ 1. 새치기
│   ├─ 지불 능력 · p55           — 지불 용의는 가치가 아니라 능력을 반영한다
│   ├─ 선물 · p64                — 콘서트는 상품이 아니라 사회적 행사 (예시: 스프링스틴 콘서트)
│   └─ 줄서기의 도덕 · p66        — 재화마다 다른 규범의 지배를 받는다 (+독자 생각)
├─ 2. 인센티브
│   ├─ 벌금 대 요금 · p99, p103   — 금전 지불이 규범 자체를 바꾼다 (예시: 어린이집 지각 벌금)
│   └─ 상품화 효과 · p108, p116, p130, p131 — 상품화 결정엔 규범 밀어내기 고려 필요 (예시: 출산 허가증)
├─ 3. 시장은 어떻게 도덕을 밀어내는가
│   ├─ 선물 · p146               — 선물은 효용이 아니라 관계의 표현 (예시: 자동차 타이어)
│   ├─ 공정성과 부패 · p157       — 시장 한계에 대한 두 가지 논거 (정의)
│   └─ 비시장 규범 밀어내기 · p162, p166 (예시: 스위스 핵폐기장, 자선 모금 실험)
├─ 4. 삶과 죽음의 시장
│   └─ 죽음의 상품화 · p193, p200  — 보험과 도박의 불안정한 공존 (예시: 말기환금, 생명보험)
└─ 5. 명명권
    ├─ 효율성 · p246              — 시장 효율 자체는 미덕이 아니다 (예시: 머니볼)
    ├─ 상업주의의 침범 · p258      — 더러워지는 것은 사과가 아니라 세상 (예시: 사과 광고 스티커)
    └─ 스카이박스화 · p275         — 계층 혼합의 상실은 민주주의의 상실 (예시: 스카이박스)
    └─ (독자 생각) 가치 부여의 역사, 민주주의 대 자본주의, 판단 회피로서의 시장주의 · 무페이지
```

**오버레이**
- **규범 밀어내기** ← p99·p116·p131·p162·p166: 책 전체를 관통하는 중심 논지 (2·3장에 걸침)
- **선물** ← p64·p146: 1장과 3장에서 같은 표제어 재등장 → 자동 링크

## 2. 정의란 무엇인가 (샌델) — 페이지 단조 정렬의 정석

목차(강 단위)가 페이지와 강하게 단조 대응. 기권 0건. 10강 중 **2강(공리주의)·3강(자유지상주의)은 수집
문장이 없어 미물질화** — fog-of-war 그대로. p41·p182·p319 같은 독자 요약 메모는 role=**독자 정리**로,
개념의 정의 앵커 역할을 한다(새 role 필요).

```
■ 정의란 무엇인가
├─ 1강 옳은 일 하기
│   ├─ 정의의 세 기준 · p41(독자 정리), p27, p28 — 복지·자유·미덕 (예시: 가격 폭리 논쟁)
│   └─ 도덕적 사유 · p53, p54     — 확신↔원칙의 변증법, 혼란이 철학의 기폭제 (예시: 동굴의 비유 비판)
├─ 4강 대리인 고용하기 — 시장과 도덕
│   ├─ 시민의 의무 · p137, p142   — 병역은 의무인가 직업인가 (예시: 모병제)
│   └─ 자유로운 선택 · p146, p149, p152 — 동의의 조건: 압력 없음 + 충분한 정보 (예시: 대리모 계약)
├─ 5강 중요한 것은 동기다 — 이마누엘 칸트
│   ├─ 의무와 경향성 · p178
│   ├─ 정언 명령 · p182(독자 정리), p184 — 보편화 원칙 = 내 욕구의 특권화 금지 (예시: 거짓 약속)
│   ├─ 자율 · p188               — 자유 = 자율 = 도덕, 하나의 개념
│   └─ 필연성과 자유 영역 · p194   — 도덕은 경험적이지 않다 (+독자 정리)
├─ 6강 평등 옹호 — 존 롤스
│   ├─ 계약의 도덕적 효력 · p219   — 자율과 호혜 (+독자 생각: 우리는 사회와 합의를 했는가?)
│   ├─ 차등 원칙 · p229           — 불평등은 최소 수혜자에게 이익일 때만 (예시: 빌 게이츠)
│   └─ 무지의 장막 · p230          — 분배는 임의적 요소에 기초하면 안 된다 (+독자 생각)
├─ 7강 소수집단우대정책 논쟁
│   ├─ 법과 사회적 의지 · p251     [확신: 중간]
│   └─ 대학의 사명 · p260          — 입학은 미덕 포상이 아니라 사명 수행
├─ 8강 누가 어떤 자격을 가졌는가 — 아리스토텔레스
│   └─ 목적론 · p286(독자 정리)    — 정의 = 텔로스 이해 + 미덕에 영예 포상
├─ 9강 우리는 서로에게 무엇을 빚지고 있는가 — 충직 딜레마
│   ├─ 좋은 삶 · p319(독자 정리)   — 자유주의 대 아리스토텔레스: 결정의 순서 [확신: 중간]
│   ├─ 부담을 감수하는 자아 · p325, p348 — 선택하지 않은 의무(연대·충성·기억)의 수용
│   ├─ 서사적 존재 · p326          — 매킨타이어: 나는 어떤 이야기의 일부인가

미물질화: 2강(공리주의), 3강(자유지상주의) — 수집 문장 없음 → 노드 미생성
```

- **자유로운 선택** ← p149(4강)·p188(5강)·p230(6강): 선택의 조건이라는 관통 질문

## 3. 그리스인 조르바 (카잔차키스) — 척추 무용 케이스 (폴백 검증)

목차가 [본문, 해설, 개역판 서문, 연보] — 위계로 쓸 수 없음 → **폴백: depth 2 (표제어 → 문장) + 오버레이**.
소설이라 거의 모든 메모가 장면·대화 = role=**장면**(예시의 변형). lift 없이는 "방앗간 마누라 엉덩이"가
노드가 된다 — '일본 자동차 문제'의 극단형이라 lift가 필수인 장르.

```
■ 그리스인 조르바 (스켈레톤 없음 → 평면 표제어 + 오버레이)
├─ 자유 · p52, p167, p393, p470
│     — 탐욕을 버리는 자유, 자유의지로 맡은 역, 벗어남으로써 가벼워짐, 피할 수 없다면 본질을 바꿔라
│       (장면: 금화 뿌리기, 연출가와의 합의, 먼지 털기)
├─ 관념과 삶 · p30, p118, p380, p432, p434
│     — 겪는 자는 쓸 시간이 없다; 추상화는 현실 도피; 지식인은 공중의 새, 조르바는 대지의 뱀
│       (장면: 방앗간 마누라 엉덩이, 뱀 숭배, 산투리)
├─ 처음 보는 눈 · p88, p99, p243
│     — 만물은 상형문자; 조르바의 말은 세상의 처녀성을 회복시킨다 (장면: 내리막의 돌)
├─ 죽음 · p70, p296 — 죽음을 생각하며 행동하기 = 죽음이 없다는 듯 행동하기 (장면: 고대 유적)
├─ 몸 · p66, p166 — 파도와 춤추는 정신; 행복은 몸 크기만 하다 (장면: 공자 인용)
├─ 낱말의 위험 · p308 — '영원' '조국' '하느님' 같은 말 속으로 뛰어드는 위험
├─ 깨어남 · p116 — 눈뜬 자에게 더 좋은 세상을 보여줄 자신이 있는가
├─ 슬픔의 관능 · p164
├─ 가르침과 배움 · p165 — 선생은 제자로부터 배운다
└─ 영혼 · p316
```

**오버레이 (책 간!)**
- **처음 보는 눈 ↔ 미지화**(디자인의 디자인): 조르바 p99·p243 = 하라 켄야의 재발견·미지화와 동일 개념.
  lift된 표제어끼리의 임베딩 매칭으로 잡히는 수준 — BKT-287 연결 레이어와 자연 통합 지점.
- **자유 ↔ 자유로운 선택**(정의란 무엇인가 4·5강): 자유의 조건이라는 질문 공유 (도발형 연결 후보).

## 관찰 (4권 종합)

1. **척추 품질 스펙트럼이 3권으로 완성됨.** 돈사것(절 단위 목차+독자 장 마커 → depth 4) >
   정의(강 단위 목차 → depth 3) > 디디(목차 불완전 → 기권 2건) > 조르바(목차 무용 → depth 2 폴백).
   같은 파이프라인이 척추 품질에 따라 깊이만 달리 낸다 — 별도 로직 분기 불필요 가설 유지.
2. **미물질화 = fog-of-war 작동 증거.** 정의 10강 중 2·3강은 노드 자체가 안 생김. 안 읽은(안 수집한)
   구조는 트리에 나타나지 않는다는 요구사항이 자연 충족.
3. **role 셋 확장 필요: 정의/주장/예시(장면)/독자 정리/독자 생각.** 독자 정리(p41, p182, p319)는
   개념의 정의 앵커로 승격 가능한 고가치 메모. 앱 데이터엔 quote/myThought 분리가 이미 있어 유리.
4. **소설은 lift가 없으면 붕괴하는 장르.** 조르바 메모는 전부 장면 — 표제어는 항상 문장 밖에 있다.
5. **책 간 연결이 표제어 레벨에서 공짜로 나옴.** 처음 보는 눈↔미지화, 샌델 2권의 시장·도덕 연속성.
   인제스트 산출물(lift된 표제어)이 그대로 BKT-287 연결 입력이 된다.
6. **정의란 무엇인가는 목차 데이터가 레포에 없었음** — 알라딘 스크레이프 커버리지가 척추 가용성을
   결정. 목차 없음 폴백만이 아니라 '목차 미취득' 폴백도 같은 경로로 처리.
