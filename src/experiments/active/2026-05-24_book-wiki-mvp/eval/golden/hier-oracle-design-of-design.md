# 위계 인제스트 oracle (best case) — 디자인의 디자인 · v2

> 작성: Claude(수작업), 2026-07-07. 입력은 Junseo 실제 수집 문장 17건(디자인의 디자인_220308_191948.md)과
> seed-v1 목차만 사용.
> v2 변경: ① 노드 제목을 키워드(표제어) 단위로 — 표제어/논지 분리 원칙 ② 메모 단위 '개념 승격' 단계 추가
> (예시 문장은 예시가 아니라 그것이 가리키는 개념으로 승격, 원문은 role=예시로 부착).
> 용도: gpt-4o-mini 파이프라인이 도달해야 할 상한선 및 eval 골든 레퍼런스.

## 명명 규칙 (표제어/논지 분리)

- **노드 제목 = 표제어**: 2~10자 명사구. 원칙적으로 수집 문장의 자구에서 뽑는다(닫힌 후보 집합).
  자구에 없으면 일반 어휘 1개로 승격하되 합성 금지.
- **"A와 B — C하는 D" 형태 금지.** 제목이 합성되려 하면 그건 개념이 2개라는 신호 → 쪼갠다.
- **논지(claim)는 제목이 아니라 노드 본문 첫 줄.** "디자인은 생활 관점의 문명 비평이다"는 본문,
  제목은 "문명 비평".

## 메모 단위 개념 승격 (per-memo lift)

각 메모를 그룹핑 전에 독립적으로 `{표제어, 논지 한 줄, role, 예시 대상}`으로 변환한다.
role: **정의 / 주장 / 예시**. 예시 판정 신호 — ① 주어가 고유명사·구체물 ② 구체물로 일반 명제를
서술하는 구조("X가 ~한 것은 ~때문이다") ③ 표제어 후보가 문장 안이 아니라 문장이 *가리키는 곳*에 있음.

| 페이지 | 표제어 | role | 논지 / 예시 대상 |
|---|---|---|---|
| p32 | 디자인의 기원 | 주장 | 러스킨·모리스(예시)의 반근대 사상이 디자인의 기원 — 만들기와 생활의 관계 |
| p33 | 테크놀로지 추종 | 주장 | 디자인이 기술의 '기묘한 과일' 프레젠테이션으로 왜곡되고 있다 |
| p35 | 창조성 | 정의 | 익숙한 것을 미지의 것으로 재발견하는 감성도 창조성이다 |
| p36 | 커뮤니케이션 디자인 | 정의 | 미디어를 횡단해 정리하는 감성. 디자인은 미디어에 종속되지 않는다 |
| p38 | 디자인의 발견 | 주장 | 생활 속 의문 발견. 그 시선 끝에 모더니즘의 미래가 있다 |
| p48 | 문명 비평 | 정의 | 디자인은 생활 관점의 문명 비평 · **예시: 화장지 심** |
| p70 | 미지화 | 정의 | 21세기 = 일상이 끊임없이 미지화되는 시대 |
| p82 | 정보의 건축 | 정의 | 정보는 접한 사람의 머릿속에 구축된다 · **예시: (나가노) 프로그램** |
| p109 | 정보의 음미 | 주장 | 저장·이동량보다 얼마나 음미하느냐가 중요 |
| p114 | 종이 미디어 | 주장 | 디지털 등장으로 종이가 본래의 소재적 매력을 회복 |
| p139 | 행위의 축적 | 주장 | 작은 행위의 축적이 닿으려면 자기 의식 속 유도 장치가 필요 |
| p148 | **욕망의 반영** | **예시** | 디자인은 사용자의 욕망 수준을 그대로 반영한다 · **예시: 일본 자동차** |
| p216 | 디자인의 기능 | 주장 | 반대 메시지가 아니라 계획을 기능하게 하는 것 |
| p219 | 디자이너의 역할 | 정의 | 커뮤니케이션 문제를 진단·치료하는 의사 · **예시: 두통약** |
| p220 | 미디어의 본질 | 주장 | 미디어 자체에 창조성을 맡기는 것은 본질 무시 (매클루언 비판) |
| p234 | 신체성의 확장 | 주장 | 정보 기술로 확장되는 시각성·신체성이 비주얼 디자인의 관점 |
| p236 | 그래픽 디자인의 쇄신 | 주장 | 갈아타지 말고 활동으로 의미를 쇄신하라 |

## 트리 (depth 3: 책 → 장 → 표제어 → 문장)

```
■ 디자인의 디자인
├─ 디자인이란 무엇인가
│   ├─ 디자인의 기원        · p32
│   ├─ 테크놀로지 추종      · p33
│   ├─ 창조성              · p35, p38
│   └─ 문명 비평            · p48 (예시: 화장지 심)
├─ 리디자인 — 일상의 20세기
│   └─ 미지화              · p70
├─ 정보의 건축
│   ├─ 정보의 건축          · p82 (예시: 프로그램)
│   └─ 정보의 음미          · p109
├─ 커뮤니케이션 디자인
│   ├─ 커뮤니케이션 디자인   · (p36→자구, 부착은 1장) ·개념 홈
│   ├─ 디자이너의 역할       · p219 (예시: 두통약), p216
│   ├─ 미디어의 본질        · p220
│   └─ 종이 미디어          · p114
├─ 비주얼 커뮤니케이션 디자인
│   ├─ 신체성의 확장        · p234
│   └─ 그래픽 디자인의 쇄신  · p236
└─ ⚠ 미분류
    ├─ 욕망의 반영          · p148 (예시: 일본 자동차)
    └─ 행위의 축적          · p139
```

주: p36 원문(페이지 단조성)은 '디자인이란 무엇인가' 장에 부착되지만, 표제어 "커뮤니케이션 디자인"은
같은 이름의 장과 자구 일치 → 문장은 1장에, 개념 링크는 해당 장 노드로 걸어준다(오버레이).

## 테마 오버레이 (트리 밖 수평 연결)

표제어 승격의 부산물로 오버레이가 자동 유도된다 — 같은/동의 표제어가 다른 장에 나타나면 링크:

- **미지화** ← 창조성(p35)·디자인의 발견(p38)·미지화(p70): 1장과 리디자인 장을 관통하는 중심 논지
- **미디어의 본질** ← 커뮤니케이션 디자인(p36)·종이 미디어(p114)·미디어의 본질(p220)·신체성의 확장(p234)
- **욕망의 반영** ← 일본 자동차(p148)·(약하게) 문명 비평의 화장지 심(p48): 사물이 사용자 수준을 비춘다

## 관찰 (파이프라인 설계에 주는 시사점)

1. **부착 = 페이지 정렬된 메모열 ↔ 목차열의 단조 정렬.** 자구 앵커로 경계 고정 + DP 전역 배치.
   LLM은 (메모, 장) 친화도 점수만. 셔플 안정성은 구조적으로 100%. p36이 반례 앵커(내용 일치를
   페이지가 기각) — 내용만 보는 부착은 여기서 반드시 틀린다.
2. **기권 버킷은 1급 기능.** oracle도 2건은 못 붙인다. 목차 품질이 기권률을 좌우.
3. **표제어/논지 분리가 명명 문제를 해결.** 제목은 자구 유래 명사구(닫힌 후보 집합)라 생성 자유도가
   낮고 런 간 재현성이 높다. 합성 제목 금지가 과응집(서로 다른 개념 뭉치기)의 감지기 역할도 한다.
4. **예시 승격(role=예시)이 '일본 자동차 문제'를 해결.** 구체물 주어 + 일반 명제 서술 구조가 신호.
   승격된 개념은 이후 다른 책·다른 메모와 병합 가능한 형태가 된다(예시 자체는 병합 불가능한 고유물).
5. **메모 단위 lift는 순서 무관·캐시 가능·4o-mini 크기의 문제.** 그룹핑과 명명이 lift 결과(표제어)
   위에서 돌므로, 남는 LLM 판단은 "같은 표제어인가(동의어 병합)"뿐이다.
6. **목차 없는 책 폴백 동일 구조**: 장 레벨만 빠진 depth 2 + 오버레이.
