## 돈으로 살 수 없는 것들 p.33

> 저장한 문장: "시장이 지닌 매력 중 하나는 스스로 만족하는 선택에 판단을 내리지 않는다는 점이다. 시장은 재화의 가치를 평가하는 방식이 다른 것보다 기준이 높은지, 혹은 더 가치가 있는지 따지지 않는다. 시장은 고개를 가로젓지 않…"


**🔔 알림 (1층)**
시장은 각자의 선택을 존중하고 가치를 따지지 않는다는 얘기야. 그래서 사람들은 자유롭게 거래를 할 수 있다는 거지.

**👆 펼치면 (2층)**
이 문장이 너한테는 어떤 의미였어?

- [ 시장의 중립성에 대한 긍정 ]
- [ 가치 판단 부재의 문제점 ]
- [ 자유로운 선택의 중요성 ]
- [ ✏️ 직접 입력 ]

## 돈으로 살 수 없는 것들 p.166

**👆 펼치면 (2층)**
이 문장이 너한테는 어떤 의미였어?

- [ 시민의 의무가 사라지는 것 ]
- [ 경제적 동기부여의 영향 ]
- [ 공공정신의 중요성 ]
- [ ✏️ 직접 입력 ]

- [ 디자이너의 책임을 강조하는 것 ]
- [ 문제의 근본을 탐구하는 중요성 ]
- [ 표면적인 해결책의 위험성 ]
- [ ✏️ 직접 입력 ]

## 무의미의 축제 p.147

> 저장한 문장: ""하찮고 의미 없다는 것은 말입니다, 존재의 본질이에요. 언제 어디에서나 우리와 함께 있어요. 심지어 아무도 그걸 보려 하지 않는 곳에도, 그러니까 공포 속에도, 참혹한 전투 속에도, 최악의 불행 속에도 말이에요. …"
> 💭 무의미를 부정하거나 극복하는 게 아니라 사랑하는 법. 저항이 아닌 수용.

**🔔 알림 (1층)**

**👆 펼치면 (2층)**
이 문장이 너한테는 어떤 의미였어?

- [ 무의미를 인정하고 돌보는 것 ]
- [ 의미에의 집착에서 벗어나는 것 ]
- [ 무의미 속에서 더 큰 의미 찾기 ]
- [ ✏️ 직접 입력 ]
