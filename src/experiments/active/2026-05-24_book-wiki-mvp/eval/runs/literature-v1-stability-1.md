# literature-v1 재현성 측정 1차 (BKT-381 남은 축 ①)

- 방법: 같은 입력을 NO_CACHE 로 3회 실행, "메모 쌍이 같은 최상위 모티프에 속하는가" 관계의 쌍별 자카드 (`eval/scripts/litStability.mjs`). 모티프 이름은 실행마다 달라지므로 메모 페이지 기준 — 비문학 memoPairRelations 와 같은 원리.
- 전제: 전수 11권(runs 49~59)은 잔류 0·커버 100% — 커버리지는 구조로 보장되므로, 남은 변동은 "어떤 문장이 어떤 축으로 묶이는가".

## 해석

- 비문학 v9(동화 우선)가 확보한 100% 와 대비되는 수준 — 문학판은 planIngestLit 의 모티프 후보·배정이 매 실행 새로 샘플링되는 구조라 그룹핑이 크게 출렁인다.
- 단, 서비스 관점 실제 시나리오는 "전량 재인제스트"가 아니라 **증분 추가**(기존 트리에 메모 1개 동화)다. 비문학이 v9에서 동화 우선으로 100%를 만든 것과 같은 경로 — 문학판 동화 모드(기존 모티프를 고정 컨텍스트로 주고 새 메모만 배정)가 자연스러운 다음 단계.
- Kimi K2.5 A/B(비용 축)와 묶어 검증 가능: 동화 모드는 콜이 작아져 저가 모델 적합성도 함께 오른다.
