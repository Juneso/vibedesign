## 돈으로 살 수 없는 것들 p.33

> 저장한 문장: "시장이 지닌 매력 중 하나는 스스로 만족하는 선택에 판단을 내리지 않는다는 점이다. 시장은 재화의 가치를 평가하는 방식이 다른 것보다 기준이 높은지, 혹은 더 가치가 있는지 따지지 않는다. 시장은 고개를 가로젓지 않…"

- [ 시장의 중립성이 매력적이다 ]
- [ 중립이 오히려 문제다 ]
- [ 선택의 자유가 중요하다 ]
- [ ✏️ 직접 입력 ]

## 그리스인 조르바 p.70

> 저장한 문장: "죽음이 없다는 듯이 행동하는 것과 매 순간 죽음을 생각하면서 행동하는 것은 어쩌면 같은 것일지도 모른다."


**🔔 메시지**
죽음을 무시하며 사는 것과 매 순간 생각하며 사는 것이 결국 같을 수도 있다는 얘기야. 죽음을 의식하든 의식하지 않든, 결국 살아가는 방식에는 큰 차이가 없을 수도 있다는 거지. 너라면 어느 쪽 삶에 더 가까운 것 같아?

- [ 죽음을 잊고 사는 게 편해 ]
- [ 죽음을 생각하며 사는 게 의미 있어 ]
- [ 죽음을 초월하는 게 중요해 ]
- [ ✏️ 직접 입력 ]

_(분기 자가 검수로 1회 재생성: 1-3 — 1과 3은 죽음을 잊고 사는 것이 결국 같은 것이라는 입장을 공유한다.)_

## 그리스인 조르바 p.432

> 저장한 문장: "나는 등잔불을 끄고 침대에 누웠다. 그리고 언제나처럼 나의 나쁜 습관에 따라, 또다시 현실로부터 피와 살과 뼈를 다 제거하여 현실을 추상 개념으로 바꾼 뒤, '이미 일어난 일들은 일어날 수밖에 없는 필연성에 의해 일…"


**🔔 메시지**

- [ 추상화로 현실의 무게를 덜어낸다 ]
- [ 현실 도피는 문제 해결을 방해한다 ]
- [ 필연성을 받아들이는 지혜 ]
- [ ✏️ 직접 입력 ]

_(분기 자가 검수로 1회 재생성: 1-3 — 추상화는 현실을 이해하거나 그 무게를 덜어내는 도구로 사용될 수 있다.)_
