## M2에서 배운 것

### 잘 된 것
- **평가 인프라 자체**: `node eval/runEval.mjs` 한 번으로 3 파이프라인 채점 + 자기평가 + 리포트 자동화. 프롬프트 바꿀 때마다 10분 이내 결과 확인 가능.
- **책 메타 주입**: 알라딘 책소개/책속에서/추천글을 `[책 보강 컨텍스트]` 블록으로 주입하니 toc 4항목짜리 조르바도 메모마다 다른 맥락 연결 가능.
- **myThought 통합 (A4 축)**: 사용자가 직접 쓴 한 줄이 thesis에 녹아들어가는 흐름 확인. wiki가 "책 요약"이 아닌 "내 사고"를 누적하는 방향으로 작동.
- **Profile → 넛지 개인화**: `interpretProfile` + `derivedKeywords` 파이프라인. 조르바 넛지에서 "정답 없는 문제의 몰입감" 키워드가 실제 질문에 반영됨.

### 어려웠던 것
- **자기평가 루브릭 안정화**: LLM이 pass/fail 기준을 일관되게 적용하기까지 루브릭 재작성 5회 + 채점 로직 코드 보정 필요. "tocAnchor=미지정이면 무조건 0" 패턴이 반복.
- **균질화 vs 인용 강제 트레이드오프**: 인용 형식 강제 → LLM이 예시 그대로 복사. 인용 강제 풀고 다양성 가이드로 전환해 해결. "형식 강제 말고 기준 강제" 원칙.
- **골든셋 규모**: N=2권/16메모. 자기평가 기준이라 실제 체감 품질과 차이 있을 수 있음.
