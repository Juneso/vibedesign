# 넛지 퀄리티 × 다양성 루브릭 v1 — DES-270 / DES-291

> 목적: 넛지를 "하나 잘 만드는" 수준을 넘어 **"연속으로 받아도 매번 새로운"** 상태로.
> V3 실패 모드(4책 모두 "디자인 리뷰에서..." 수렴)와 V5 단일 로직의 템플릿화를 정량 검출한다.
>
> 평가 단위가 2개다:
> - **퀄리티 (QA~QD)**: 넛지 1개 단위. 기존 4축 유지.
> - **다양성 (D1~D5)**: 책당 배치 N=4 단위 (D1~D4) + 전체 4책 배치 단위 (D5).

---

## 퀄리티 축 (넛지 1개 단위) — 기존 정의 유지

| 축 | 의미 | 2점 기준 |
|---|---|---|
| QA 근거 강제 | 질문이 실제 페이지 내용으로 역추적 가능 | 모든 내용이 근거 페이지로 역추적. 책 원문 추론 0건 |
| QB 이해가능성 | 책을 안 읽어도 이해 가능 | 인용+덧붙인 맥락만으로 한 번에 이해됨 |
| QC 구체성 | 구체적 장면이 그려짐 | 책 속 사례든 일상 장면이든 특정 순간을 머릿속에 그릴 수 있음 |
| QD 정지력 | 스쳐 읽다 멈추게 함 | 예상 밖의 각도. "아, 이거" 하는 느낌 |

> co-reader 형식 주의: 넛지가 의문문이 아니어도 된다. "AI 생각 + 대화 초대" 구조 전체를 평가한다.

## 다양성 축 (배치 단위)

### D1. 앵커 다양성 — 같은 메모·같은 문구에 수렴하지 않는가
- **2**: N개 넛지의 앵커 메모 집합이 전부 다름. 인용 문구 중복 0건.
- **1**: 1쌍이 같은 메모를 쓰지만 다른 문구·다른 각도로 사용.
- **0**: 2개 이상 넛지가 같은 메모·같은 문구에 수렴.

### D2. 각도 다양성 — AI 해석의 사고 패턴이 겹치지 않는가
앵글 팔레트: `reframe`(재해석) / `tension`(긴장 발견) / `cluster`(메모 간 연결) / `everyday`(일상 장면) / `profile`(개인화) / `counter`(부드러운 반론)
- **2**: 배치 내 모든 넛지의 해석 각도가 구분됨. 선언된 angle과 실제 내용이 일치.
- **1**: 2개가 실질적으로 같은 각도이나 내용은 다름.
- **0**: 절반 이상이 같은 사고 패턴 반복 (angle 라벨만 다르고 내용 동형).

### D3. 문형 다양성 — 표면 형식이 템플릿화되지 않는가
- **2**: 도입부 구조와 대화 초대 문구가 모두 다름. 문장 리듬도 단조롭지 않음.
- **1**: 초대 문구 1개 중복, 또는 도입부 구조("\"인용\"이 흥미로워" 패턴) 2회 반복.
- **0**: 동일 템플릿("~가 흥미로워. 넌 어떻게 봤어?")이 3회 이상.

### D4. 연결타입 다양성 — 단일메모 재해석 단일형이 아닌가
- **2**: 배치에 단일메모 / 클러스터(2~3메모) / 프로필 연결 중 **3종 이상** 포함.
- **1**: 2종.
- **0**: 전부 같은 연결타입.

### D5. 책 간 비수렴 (전체 4책 단위) — V3 실패 모드 검출
- **2**: 책이 다르면 넛지의 상황·표현·구조가 모두 책 고유. 책을 가리고 읽어도 어느 책 넛지인지 구분 가능.
- **1**: 2권에서 비슷한 표현·상황 패턴 재사용.
- **0**: 동일 템플릿(예: "디자인 리뷰에서 의사결정이 막힌 순간...")이 3권 이상에서 반복.

## 프로그램 검증 (judge 외 결정적 체크)

LLM judge와 별개로 스크립트가 직접 계산:
- **앵커 중복률**: 플랜의 anchorMemoIdx 집합 간 교집합.
- **도입부 중복**: 각 넛지 첫 12자 정규화 후 일치 여부.
- **초대 문구 중복**: 각 넛지 마지막 문장 정규화 후 유사(공백 제거 후 동일) 여부.

judge 점수와 프로그램 체크가 충돌하면 낮은 쪽을 채택 (suspect 처리).

## 합격 기준

| 영역 | 기준 |
|---|---|
| 퀄리티 | 모든 넛지가 QA~QD 전 축 ≥ 1 (0점 축 없음) AND 4축 평균 ≥ 1.5 |
| 다양성 (책 단위) | 각 책의 D1~D4 모두 ≥ 1 AND 합 ≥ 6/8 |
| 다양성 (전체) | D5 ≥ 1 |
| 종합 | 위 3개 모두 충족 시 라운드 합격 |

> 비교 베이스라인: V5 단일 프롬프트를 N회 반복 호출한 배치. V7이 퀄리티를 잃지 않으면서(QA~QD 평균 동등 이상) 다양성(D합)에서 유의하게 앞서야 채택.
