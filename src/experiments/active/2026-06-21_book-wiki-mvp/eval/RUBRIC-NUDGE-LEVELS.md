# 넛지 응용 거리 7단계 루브릭 — V8 설계 기준

> 2026-06-10 기획 검토에서 도출. V7(judge 합격)이 실사용 기준으로는 자극적·산만하다는 피드백 후,
> "적은 문장을 풀어주는 것이 공감의 본체, 응용은 살짝"이라는 원칙으로 재정의.
> Junseo 본인 캘리브레이션 완료 (메모 2개 × 7레벨 배리에이션 비교).

## 7단계 정의

| 레벨 | 정의 | 질문 위치 |
|---|---|---|
| L1 | 순수 풀이 — 적은 문장을 더 쉬운 말로 다시 말해줌 | 없음 |
| L2 | 풀이 + 밑줄 친 마음 짚기 (myThought 공감 한 줄) | 없음 |
| L3 | 풀이 + 문장 안에서 묻기 | 문장 안 |
| L4 | 풀이 + 책 맥락 반걸음 — 같은 책의 흐름과 연결 | 책 안 |
| L5 | 풀이 + 보편 일상 반걸음 | 일상 |
| L6 | 풀이 + 유저 맥락 한 걸음 (직업·관심사) | 유저 삶 |
| L7 | 전이·반론 — 문장을 뒤집거나 다른 영역에 적용 | 책 밖 |

## 캘리브레이션 결과 (2026-06-10, Junseo)

- **L1~L2**: 가장 잘 읽힘. "끄덕하고 끝" — 단, 이 끄덕임이 재마주침(spaced repetition) 가치의 본체.
- **L4**: 생각해볼 지점을 만듦. 단 어렵고, 자유 텍스트 답변 전환은 기대하기 어려움.
- **L5~L7**: 책의 맥락에서 멀어짐. V7과 Claude 직접 작성 넛지가 자극적·산만하게 느껴진 원인.

## V8 설계 원칙 (넛지 = 리텐션 엔진)

1. **목적 재정의**: 위키 풍부화는 인제스트 시점이 본체. 넛지의 주목적은 리텐션(재마주침). 답변은 보너스.
2. **2층 구조**: 알림 = L1~L2 해석 (그 자체로 완결, 안 눌러도 가치). 펼치면 L3~L4 질문.
3. **원터치 답변**: 질문에는 "서로 다른 읽기 3개" 선택지 — 정답 후보가 아니라 자기표현.
   선택도 구조화 데이터 ("이 문장을 X로 읽음")로 위키 적재 가능. 직접 입력은 보너스 → 위키 적재.
4. **레벨 분포**: L2 기본 + L4 질문. L5~L6은 가끔(앵커가 자연스러울 때만). L7 금지.
5. **채점 루브릭 교체 예정**: QD(정지력) 중심 → 풀이 정확도·공감 + 응용 거리 적정성 중심.
   콜드 푸시 자유답변 전제는 폐기 — 측정은 열람/탭/입력 3층 퍼널로.

## 검증 계획

N=1, 2주: 레벨 섞어 실제 푸시 → 레벨별 ①열람 ②선택지 탭 ③직접 입력 기록.
이 데이터가 V8 생성 로직(레벨 분포·선택지 설계)의 설계도가 된다.
